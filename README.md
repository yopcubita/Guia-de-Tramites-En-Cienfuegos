# Guía de Trámites en Cienfuegos 🇨🇺  
Sitio web informativo y práctico que reúne los principales trámites que los ciudadanos de Cienfuegos necesitan realizar: pasaporte, TCP, notaría, vivienda, ONAT, certificaciones, bancos y transporte.  
Incluye mapa interactivo, diseño moderno, navegación clara y contenido optimizado para SEO.

🔗 **Sitio en vivo:**  
https://yopcubita.github.io/Guia-de-Tramites-En-Cienfuegos/

---

## 📌 Características principales

- **8 páginas internas** con información detallada de cada trámite.
- **Mapa interactivo** con Leaflet mostrando oficinas, bancos y puntos importantes.
- **Diseño responsive** compatible con móviles, tablets y PC.
- **Modo oscuro** activable desde la barra de navegación.
- **Buscador interno** para encontrar trámites rápidamente.
- **SEO optimizado** con meta tags, JSON-LD, sitemap y robots.txt.
- **Código limpio y organizado** en HTML, CSS y JavaScript puro.
